# Support Policy

## Supported releases

| Release | Status | Security fixes |
|---|---|---|
| `v0.1.0` (current, initial release) | ✅ Supported | ✅ Yes |
| Older versions | ❌ Not supported | ❌ No |

- **Scope of support**: the SDK packages (`packages/*`) and smart contracts
  (`contracts/*`) in this repository, as consumed from source by VaultKeepR
  clients.
- **Duration**: the latest release line receives security updates as long as
  it is the current release. Each new release supersedes the previous one;
  only the latest release line receives security fixes.
- **End of security updates**: a release stops receiving security updates
  immediately when a newer release is published. The
  [CHANGELOG](./CHANGELOG.md) and GitHub Releases announce each new version.

## How to get support

- **Security vulnerabilities**: private report only — see
  [SECURITY.md](./SECURITY.md) (48 h acknowledgement target).
- **Bugs and usage questions**: open a
  [GitHub issue](https://github.com/VaultKeepR/vaultkeepr-public/issues) —
  see [CONTRIBUTING.md](./CONTRIBUTING.md) for what to include.
